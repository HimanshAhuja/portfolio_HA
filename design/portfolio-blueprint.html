Interactions

core = launch, stretch = after launch
Title screen + name rise core

The site opens on your name, letter by letter, over a thin rule that draws outward, then "Press any key". On start the name lifts slightly, glides up into the header, and the menu loads in beneath it: rules, list items one by one, then the content. About 2.5 s in total.

Background music core

Browsers block sound until the visitor interacts, so the title screen's key press starts the music. A BGM button in the header plays or pauses it at any time (shortcut M), and the choice is remembered on the next visit.

Keyboard + controller-feel nav core

W/S or arrows move the selection, Enter opens, Esc goes back. The cursor glides between items. Mouse and touch work the same as on any site.

Screen transitions core

Short horizontal slice glitch between menus (320 ms). Content fades up in staggered rows, matching how the game paints list items.

Pod companion core

A small pod in the corner posts "Proposal:" hints that point visitors at the best content (bitkv first). Clicking it cycles tips; it can be dismissed.

Weapon upgrades core

Each project starts at LV 1 with a one-line story. Upgrading reveals the next paragraph of detail. A "Max level" shortcut shows everything for skimmers.

Plug-in chips core

Skills as chips with a storage cost. Toggling a chip highlights the projects that use it, which ties skills to evidence.

Menu sound core

Synthesized cursor blips and confirm tones with the Web Audio API, no audio files. Separate from the music and off by default; toggle in System.

Skill map stretch

Force-directed graph of projects and skills with drag, zoom and hover tracing, styled after your graph-view reference.

Hacking minigame stretch

Hidden twin-stick bullet-hell on a canvas, opened from the terminal or by typing "hack". Clearing it unlocks the resume download and a secret Intel file.

Terminal stretch

Press ~ for a command line: help, ls weapons, cat bitkv, redis-cli PING. A wink at bitkv's Redis protocol.

Build order

each phase ends in something you can click
PHASE01Foundation
Scaffold and content model
  • Vite + React + TS project, Git repo, Vercel preview deploy
  • tokens.css, fonts, background grid and ornaments
  • All resume content typed into src/content/

Done when: a deployed page shows the sand ground, ornaments and your name.

PHASE02UI kit
Menu components
  • MenuList with selection state, cursor, keyboard nav hook
  • Panel, InfoBar with key hints, Pod, LevelBar, Chip
  • Shell layout: header, nav, content view, info bar; mobile tab bar

Done when: the prototype above works in React with real routing.

PHASE03Screens
All seven menus with content
  • Status, Quests, Weapons (with upgrades), Chips (with project highlight)
  • Intel archive, System settings and contact links
  • Simple static Map first; force graph comes later

Done when: every resume fact is reachable and the site is usable without any animation.

PHASE04Feel
Motion, sound, boot
  • Title screen, name-rise animation, staggered page load; shorter version for returning visitors
  • Music player with play/pause, fade in and out, remembered choice
  • Glitch transitions, cursor glide, menu sounds, hacking-mode theme

Done when: it feels like the game on desktop and stays calm under reduced motion.

PHASE05Ship
Polish and launch
  • Mobile pass at 375 px, focus states, screen-reader labels
  • SEO meta, Open Graph image in the menu style, favicon
  • Lighthouse 90+ on performance and accessibility, custom domain

Done when: the link is on your LinkedIn and GitHub profile.

PHASE06Stretch
Easter eggs
  • Force-directed skill map
  • Terminal overlay with commands
  • Hacking minigame that unlocks the resume PDF

Done when: you want it. None of this blocks launch.

Decisions before we build

defaults in grey
!

Which music plays?

The NieR:Automata soundtrack belongs to Square Enix, so hosting the MP3 on a public site can get a takedown notice. Options: a royalty-free ambient piano or choir track in the same mood (recommended), an original loop like the placeholder in the prototype, or a visible YouTube or Spotify player for the official OST, which is allowed but shows their player and doesn't loop cleanly. Changing the track later is a one-line change.

!

Phone number on a public site?

Default: leave it off. Email, LinkedIn and GitHub are enough, and the downloadable PDF can still carry it.

?

Unit codename shown in the header.

Default: "Unit H.A". Could be anything; avoid the game's real names (2B, 9S, YoRHa) and its logo, fonts and music, which are Square Enix property.

?

Photo or avatar on the Status screen.

Default: a line-art silhouette in ink. A real photo works too, desaturated to match the palette.

?

Contact form or links only.

Default: links only at launch. A "Transmit" form needs a small serverless function or a form service, which we can add in phase 05.

?

Domain.

Default: a free vercel.app subdomain until you pick one, such as himanshahuja.dev.
